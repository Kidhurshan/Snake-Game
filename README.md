##🐍 Snake Game

Welcome to the Snake Game! 🎮 Built entirely in Java. 🚀

#📂 Files Overview:
- SnakeGame.java: Contains the main method to start the game. 🏁
- GameFrame.java: Sets up the game window. 🖼️
- GamePanel.java: Handles the game logic and visuals. 🎨

#🎮 How to Play:
- Use W, A, S, D keys to control the snake's direction. ⬆️⬇️⬅️➡️
- Eat the food to grow your snake. 🍎
- Avoid hitting the walls or yourself to stay alive. ⚠️

Have fun! 🕹️🐍
